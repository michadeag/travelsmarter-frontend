What's the International Dial Code for Australia?

Australia's international calling code is +61, and the domestic trunk prefix is 0, which is dropped when dialing from abroad. For example, a Sydney number listed locally as (02) 9876 5432 is dialed internationally as +61 2 9876 5432.

Australian landline numbers are structured with a one-digit area code (2 for NSW/ACT, 3 for VIC/TAS, 7 for QLD, 8 for SA/WA/NT) followed by an eight-digit local number. Mobile numbers start with 04 domestically, so a mobile listed as 0412 345 678 becomes +61 412 345 678 from overseas — again, drop the leading 0. The +61 country code applies uniformly across the entire country with no regional exceptions.

Frequently asked questions

Do I need to dial anything different for Australian mobile numbers from overseas?

No special treatment is needed beyond the standard rule: replace the leading 0 with +61. So 0412 345 678 becomes +61 412 345 678. Australian mobiles all begin with 04 domestically, which becomes 4 after the country code.

What prefix do I dial before +61 if I'm calling from a landline or a country that doesn't use + notation?

You dial your country's international exit code first, then 61. From the US or Canada that's 011 61, from the UK it's 00 61, and from most of continental Europe it's also 00 61. The + symbol in +61 is just a universal shorthand for whichever exit code applies in your location.

Are there any Australian numbers that work differently, like toll-free or premium lines?

Yes — Australian 1800 numbers (toll-free) and 13/1300 numbers (national rate) generally cannot be reached from outside Australia, or may not function as intended internationally. If you need to contact a business before you arrive, look for an alternative direct geographic number or check if the company lists an international contact line.
