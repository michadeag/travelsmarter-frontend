What's the International Dial Code for Australia?

Australia's international calling code is +61, and the domestic trunk prefix is 0, which is dropped when dialing from abroad. For example, a Sydney number listed locally as (02) 9876 5432 is dialed internationally as +61 2 9876 5432.

Australian local numbers are typically written with a leading 0 as part of the area code (e.g., 02 for Sydney/NSW, 03 for Melbourne/VIC, 07 for Queensland, 08 for WA/SA/NT). When dialing from outside Australia, you replace that leading 0 with the country code +61. Mobile numbers follow the same rule: a mobile listed as 0412 345 678 becomes +61 412 345 678 from abroad.

💡 Save Australian contacts in your phone in international format (+61 then the number without the leading 0) — that way the number works whether you're calling from home, on roaming in Australia, or from a foreign SIM.

Frequently asked questions

Do Australian mobile numbers use the same +61 country code as landlines?

Yes, all Australian numbers — landlines and mobiles — use +61. A mobile number like 0412 345 678 is dialed internationally as +61 412 345 678, simply dropping the leading 0.

What area codes exist in Australia and how do I know which one to dial?

Australia has four main geographic area codes: 02 (NSW and ACT), 03 (VIC and TAS), 07 (QLD), and 08 (WA, SA, and NT). Mobile numbers start with 04. When dialing internationally, drop the leading 0 from whichever area code applies.

How do I dial Australia from the United States?

From the US, dial 011 (the US international exit code) then 61 (Australia's country code) then the local number without its leading 0. Alternatively, just use the + symbol on a mobile phone: +61 followed by the number without the 0.
