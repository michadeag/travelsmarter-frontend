What's the International Dial Code for Vietnam?

Vietnam's international calling code is +84, and its domestic trunk prefix is 0. To call a Vietnamese mobile number like 0912 345 678 from abroad, dial +84 912 345 678 (drop the leading 0).

When dialing into Vietnam from another country, replace the leading 0 of any Vietnamese phone number with the country code +84. Vietnamese mobile numbers are typically 10 digits starting with 0 (e.g., 09xx, 07xx, 08xx), while landline numbers also begin with 0 followed by an area code. The trunk prefix 0 is used only for domestic calls within Vietnam and is always dropped for international dialing — this is the standard convention used in most countries worldwide, nothing unusual.

💡 Save Vietnamese contacts in your phone in international format (+84 followed by the number without the leading 0) so the number works correctly whether you're calling from abroad or from a local SIM inside Vietnam.

Frequently asked questions

Do I need to dial a trunk prefix when calling between cities inside Vietnam?

Yes, within Vietnam you keep the leading 0 for all calls — local, long-distance, and mobile. For example, to call a Hanoi landline (024 xxxx xxxx) from Ho Chi Minh City, you dial the full 11-digit number including the 0. Only drop the 0 when calling from outside Vietnam.

What format do Vietnamese mobile numbers come in?

Vietnamese mobile numbers are 10 digits long and begin with 0, typically followed by 7x, 8x, or 9x (e.g., 0912 345 678 or 0765 432 100). Different prefixes belong to different carriers such as Viettel, Mobifone, and Vinaphone, but the format is consistent across all of them.

How do I dial out of Vietnam to call my home country?

To make an international call from Vietnam, dial 00 (the international access code) followed by the destination country code and the local number. For example, to call a US number, dial 00 1 followed by the area code and number. Many smartphones handle this automatically if you use the + symbol instead of 00.
