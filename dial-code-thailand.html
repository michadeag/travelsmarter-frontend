What's the International Dial Code for Thailand?

Thailand's international calling code is +66, and the domestic trunk prefix is 0 — drop the 0 when dialing from abroad. For example, a Bangkok number listed locally as 02-123-4567 becomes +66 2 123 4567 when dialed internationally.

Thai phone numbers are 9 digits when written with the trunk prefix 0 included (e.g., 02-XXX-XXXX for landlines, 08X-XXX-XXXX or 09X-XXX-XXXX for mobiles). When dialing from outside Thailand, replace the leading 0 with the country code +66. Mobile numbers in Thailand typically start with 06, 08, or 09 in their full local format.

💡 Save Thai contacts in your phone in international format (+66 followed by the number without the leading 0) so they work whether you're calling from a foreign SIM, a local SIM, or Wi-Fi calling apps like WhatsApp.

Frequently asked questions

Do I need to dial anything special before +66 depending on my country?

You need your country's international exit code before +66 if you're not using the + symbol. For example, from the US you'd dial 011 66, from the UK 00 66. Using the + symbol (as on most smartphones) handles this automatically regardless of where you're calling from.

How many digits does a Thai phone number have?

Thai phone numbers are 9 digits including the trunk prefix 0, which means 8 significant digits follow the 0. Bangkok landlines follow the pattern 0X-XXXX-XXXX (9 digits total), while mobile numbers follow 08X-XXX-XXXX or 09X-XXX-XXXX (10 digits total including the 0). When dialing internationally, remove the 0 and add +66.

Will my phone work in Thailand, or do I need a local SIM?

Most modern unlocked smartphones work in Thailand, which uses GSM networks on common bands. International roaming is available but can be expensive; tourist SIMs are cheap and widely available at Suvarnabhumi and Don Mueang airports as well as convenience stores like 7-Eleven. A local SIM gives you a Thai number starting with 06, 08, or 09.
