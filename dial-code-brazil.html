What's the International Dial Code for Brazil?

Brazil's international calling code is +55, and there is no single fixed trunk prefix — Brazil uses a carrier selection code (two digits) before the area code for domestic long-distance calls.

To call a Brazilian number from abroad, dial +55, then the two-digit area code (DDD), then the local number — no trunk prefix is needed when dialing internationally. Domestically, long-distance calls historically required a two-digit carrier code (e.g., 0 + carrier + DDD + number), though this system has been simplified over time and many mobile users no longer worry about it in practice. Mobile numbers in Brazil have 9 digits (starting with 9), while landlines typically have 8 digits, and both follow the +55 + DDD + local number format from abroad. São Paulo's area code is 11, Rio de Janeiro's is 21, as common reference points.

💡 Save Brazilian contacts in your phone as +55 (DDD) XXXXX-XXXX — this format works from anywhere in the world and sidesteps any confusion about domestic carrier codes.

Frequently asked questions

How do I dial a Brazilian mobile number from the US?

Dial 011 (US exit code) + 55 (Brazil country code) + the two-digit area code + the 9-digit mobile number. For example, a São Paulo mobile would be: 011 55 11 9XXXX-XXXX. If you're using a smartphone, you can simply use the + symbol instead of 011.

Why does a Brazilian mobile number have 9 digits but a landline only 8?

Brazil added a ninth digit (always a 9) to mobile numbers starting in 2012 to accommodate growing demand for numbers. Landlines retained 8 digits. This means a São Paulo landline looks like +55 11 XXXX-XXXX, while a mobile is +55 11 9XXXX-XXXX.

Do I need to include a carrier selection code when calling within Brazil?

For domestic long-distance calls made inside Brazil, the traditional format requires a carrier code (called a CSP code, e.g., 021 for Claro or 041 for TIM) inserted after the 0 trunk digit. However, many smartphones and VoIP apps handle this automatically, and the requirement has become less visible to everyday users. When dialing from outside Brazil, you simply use +55 and skip the carrier code entirely.
